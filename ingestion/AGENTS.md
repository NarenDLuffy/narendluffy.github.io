# Ingestion rules

- Rooms are one per (online|offline, cell colour) across ALL schedule files, merged in ingestion/room_resolver.py; names come from any file (colour legend above a table, one-room table headings) and never create a column alone; explicit “Main session”/“RAN1 #N commences” marks Main — no chair names, room counts or positions are hard-coded.
- A name-only room is folded into the coloured room whose schedule clearly agrees with it (same date, overlapping time, same or parent/child agenda; name similarity lowers the bar but never merges alone) — the same room is often named differently across chair files.
- Schedule times are never invented: a block splits only when items have stated minutes that fit; otherwise it stays one block listing its items (stated minutes kept, mismatch noted). Same-slot claims from several files resolve to the most detailed, chairs' own tables ranked above copies of the shared grid.
- Schedule ancestry and specificity normalize terminal `.x` to the branch through canonical_schedule.is_descendant; block parsing shares this rule — explicitly timed children replace wildcard containers without counting parent minutes twice.
- Schedule blocks with only a topic name get their agenda code from chair-notes agenda titles via ingestion/topic_agenda_mapper.py, linked only on a unique match — so agenda filters catch them without guessing.
- DOCX schedule ingestion reads only active visible Word runs: highlighted and inserted text stays, while deleted, hidden, and struck-through text is excluded — withdrawn agenda items must never enter the canonical schedule.
- Any time span a schedule document fills in a room but the published timetable leaves empty blocks the publish (ingestion/live.py coverage_gaps → validator) — a dropped item must never go out silently; vertical-merge continuation rows are never re-read, because Word drops their lane colour.
- Every parsed block records its table cell (SessionSourceRef.cell); ingestion/live.py cell_checks refuses one cell in two rooms and the same agenda item in two rooms at once unless one document lists it in two cells — catches Word merge/colour quirks without pictures.
- Schedule granularity: live.granularity_checks flags any published block a schedule document splits more finely (status page + Verify data); ingestion/audit_granularity.py sorts them into known causes — fix the general parse rule with a test from the real cell, never one cell by name.
- Block parsing reads ranged heads "(a-b)" (items' minutes must sum inside the range) and bare top-level codes only at the start of a timed item line; a whole block whose minutes don't add up ranks below any document's tiling.
- Tables that tile the same items at different times are a disagreement, not lost detail: canonical notes "Another schedule table lists…" on the kept blocks and granularity_checks ignores parts naming other items.
- Latest-change rule (ingestion/revision_diff.py): each block's introducedAt is when its content first appeared in its own document family (walk back through older revisions, times from docProps/core.xml, signatures cached in edit-history.json); same-slot and overlap ranking put the freshest edit before file counts — stale copies in other chairs' files must not out-vote an edit. Unknown ("", first release) falls back to the older rules.
- A whole day/slot with missing or white shading keeps distinct room columns only when unmerged columns have a unique, distinct table-wide colour pattern; merged, continuation and break cells never vote for column identity — omitted shading must not move every room into Main.
